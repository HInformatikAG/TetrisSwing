# Tetris für die Java-AG

Die Hoffrogge Java-AG bringt SchülerInnen der Jahrgangsstufen 10+ die Grundlagen von Java anhand einer eigenen Tetrisimplementierung bei. Vorgegeben sind Spielfeld und Spiellogik, die Teilnehmenden der AG sollen die sieben Tetrisspielsteine implementieren, dazu gehört die grafische Darstellung (Swing) sowie die Logik/das Verhalten der Spielsteine.
