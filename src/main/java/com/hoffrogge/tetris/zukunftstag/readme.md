# Tetris für den Zukunftstag

## [Der Zukunftstag](https://www.google.com/search?q=Zukunftstag)

Für den Zukunftstag gibt es im Tetris eine vereinfachte Aufgabe: Die TeilnehmerInnen sollen einen beliebigen Stein zeichnen und das Bewegen nach links/rechts implementieren, alles andere wird vorgegeben.
